# Product Spec

AgentHub is an IM-style multi-agent collaboration platform for AI-assisted development tasks.

## Core Users

- Developers who want conversational task execution.
- Teams that need visible multi-agent collaboration history.
- Demo reviewers who need a stable, understandable end-to-end flow.

## P0 Flow

1. Create or select a conversation.
2. Send a development request with `@Orchestrator` or a direct Agent mention.
3. See Orchestrator task breakdown.
4. See Agent messages and structured artifacts.
5. Apply workspace changes.
6. Preview the result.
