# Demo Script

1. Create a conversation named `Todo App Development`.
2. Send: `@Orchestrator 帮我做一个简洁的 Todo List 网页`.
3. Show the task breakdown.
4. Show Code Agent output and diff artifact.
5. Apply the diff.
6. Show Review Agent suggestions.
7. Show Preview Agent preview card.
8. Ask for a small visual change and repeat the diff/preview loop.
